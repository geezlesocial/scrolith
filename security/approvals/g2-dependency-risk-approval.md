## 4. Acceptance rationale

A compatible Prisma 7 upgrade that resolves the `deepmerge-ts` and `mysql2`
advisories has not yet been validated.

The available audit resolution must not be applied if it requires an
incompatible Prisma downgrade or creates an unvalidated migration risk.

The temporary risk is accepted because:

1. The dependencies are present in the build/CI dependency graph.
2. They are not used by the production application request path.
3. They are absent from the final production runtime image and runtime SBOM.
4. The final runtime image reports zero Critical and zero High Trivy findings.
5. Prisma validation, generation, migrations, seed, tests, TypeScript, Docker,
   Gitleaks, and SBOM checks passed.
6. The risk has a defined expiration date, remediation deadline, and retest plan.

This approval does not authorize:

- downgrading Prisma 7;
- using `npm audit fix --force`;
- manually editing the lockfile;
- suppressing npm audit, CodeQL, Trivy, or Gitleaks findings;
- placing the affected packages into the production runtime image;
- ignoring a future runtime-image or severity change;
- deploying if this approval is expired or revoked.

## 5. Compensating controls

- The final runtime image excludes build and migration tooling.
- The runtime image runs as the non-root user `appuser`.
- Runtime Trivy scanning is required for every release candidate.
- IaC Trivy scanning is required for every release candidate.
- Gitleaks scanning is required.
- CycloneDX SBOM generation is required.
- Production-only and full npm audits run in authoritative CI.
- Prisma validation, generation, migrations, seed, tests, TypeScript, and Docker
  checks are required.
- The final runtime image and SBOM must be reviewed after dependency changes.
- The exception is revoked if either package enters the runtime image.
- The exception is revoked if a Critical or High runtime vulnerability appears.
- The dependency graph is reviewed during every release and dependency upgrade.
- No production deployment may proceed if this approval expires or is revoked.
- Any material change to Prisma, the lockfile, Docker build stages, or runtime
  dependencies requires a new security review.
