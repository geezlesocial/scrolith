# Scrolith Android Production Release 1.1.52

Version code: 62

## Release notes

<en-US>
This release adds caption support for Stories, photo and video posts, and Scroll videos. It includes a review-before-publish story flow, clearer media caption controls on mobile and desktop, live Scroll caption previews, and the latest production stability updates.
</en-US>

## Included updates

- Story caption support before publishing.
- Photo and video post caption support across mobile and desktop surfaces.
- Scroll video caption preview support.
- Production frontend update synced into the Android wrapper.
