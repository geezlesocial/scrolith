# Scrolith Android Production 1.1.56

Version code: 66

## Google Play Release Note

```text
<en-US>
This release adds company-linked profile experience editing. Users can connect existing Scrolith company pages to their work history, add working dates, mark current roles, and keep profile experience synchronized across web and mobile.
</en-US>
```

## Included

- Company page lookup while editing profile work experience.
- Working-from, working-to, and currently-working fields.
- Company page owner/admin notifications when a member newly adds the company as profile experience.
- Backend validation for company page links before profile data is saved.

## Compatibility

- Web desktop, web mobile, and Android Capacitor app share the same profile experience behavior.
- No database migration is required.
