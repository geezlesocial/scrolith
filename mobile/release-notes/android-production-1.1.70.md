# Scrolith Android 1.1.70

## Summary
Device Security production release with trusted-device sign-in approval, native biometric unlock, login alerts, and session hardening.

## Included
- Secure new-device sign-in approval with approve/reject from an already trusted device
- Fingerprint Unlock with native Android biometric protection
- Trusted-device management and stronger device/session safeguards
- Login Alerts for new sign-in activity
- ECDSA P-256 trusted-device possession proof, replay protection, and approval race protection
- First-device bootstrap compatibility and missing-device-metadata hardening
- Existing KYC Azure Blob production fix and all previously working Scrolith functionality
- Performance improvements and stability fixes
