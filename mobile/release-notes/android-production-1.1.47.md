# Scrolith Android 1.1.47 (57) - Production Release Notes

This release improves real-time voice and video calling visibility across Android, mobile web, and desktop web.

## What's new

- Added clear color-coded call controls for answer, end call, mute, speaker, video, camera, and participant actions.
- Added visible labels under call buttons so users can understand every action from caller and receiver screens.
- Changed the call close action into a true minimize action so an active call stays available as a floating in-app call pill until it is reopened or ended.
- Preserved existing voice/video calling, ringtone, TURN, messaging, media, and admin video-call controls.

## Google Play Release Note

This release improves Scrolith voice and video calls with color-coded controls, clearer labels for mute, speaker, video, camera, answer, and end-call actions, plus a minimized active-call overlay that stays available while users move through the app. It also includes the latest production stability, media, messaging, and performance updates.
