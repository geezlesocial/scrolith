# Scrolith Android Production 1.1.54

## Release notes

This release makes media captions explicit: captions appear on post videos, Stories, and Scrolls only when you add one. It also adds caption tools for emojis, professional cleanup, highlights, calls to action, @mentions, and #tags, optimized for Android and mobile web.

## Included

- Explicit media caption authoring for post video cards, Stories, and Scroll videos.
- Caption design tools for professional cleanup, highlights, calls to action, and emoji insertion.
- @mention and #tag rendering support in caption previews and published video overlays.
- Mobile-compatible caption controls for the Android WebView build.

## Not included

- No automatic captions are generated or attached to posts, Scrolls, or Stories.
- No backend, database, payment, authentication, or Scrolitha provider changes.
