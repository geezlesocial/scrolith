# Scrolith Android Production 1.1.55

Version code: 65

## Google Play Release Note

```text
<en-US>
This release hardens media captions so uploaded file names never appear as captions. Captions on photos and videos now display only when manually added, with continued support for emoji, @mentions, #tags, and polished caption tools.
</en-US>
```

## Included

- Manual-only media captions for post cards, stories, and scroll media.
- Photo and video caption overlays display only when the user writes and applies a caption.
- Uploaded file names, storage object names, titles, and alt text are not treated as captions.
- Continued support for emoji, @mentions, #tags, and caption design tools.

## Compatibility

- Web desktop, web mobile, and Android Capacitor app use the same caption rules.
- No backend migration, API change, or database change is included.
