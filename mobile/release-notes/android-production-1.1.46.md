# Scrolith Android 1.1.46 (56) - Production Release Notes

This release improves real-time voice and video calling across Scrolith.

## What's new

- Added a full-screen enterprise call experience for outgoing, connecting, ringing, active, and incoming calls.
- Added in-call controls for ending calls, muting the microphone, speaker output, switching from voice to video, and turning the camera on or off during video calls.
- Improved voice-call visibility so users can clearly see when a call is connecting, ringing, or active.
- Improved video-call layout with remote video, local preview, and camera-off states.
- Preserved existing Scrolith calling, ringtone, TURN, messaging, media, and admin controls.

## Google Play Release Note

This release adds an upgraded Scrolith calling experience with clear ringing and connecting screens, improved voice and video call controls, camera toggle support, speaker and mute controls, and smoother cross-device call handling. It also includes the latest production stability, messaging, media, and performance updates.
