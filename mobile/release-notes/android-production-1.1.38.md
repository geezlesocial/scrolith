# Scrolith Android 1.1.38 (48) - Google Play Production Release Notes

## Google Play release notes (<en-US>, under 500 characters)

Scrolith 1.1.38 restores the original Scrolitha assistant with the official Scrolith logo and removes the overlapping Scrolitha Copilot surface. Messaging assistant responses now use the production Ollama path with improved timeout handling and clearer failure recovery. This release also includes the latest production web updates and routine Android stability improvements.
