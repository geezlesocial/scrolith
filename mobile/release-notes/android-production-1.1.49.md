# Scrolith Android 1.1.49 (59)

## Google Play Release Note

<en-US>
This release improves Scrolith voice and video calls across Android devices. Active call controls now stay visible over direct message conversations, calls can be minimized without disconnecting, and audio playback has been tuned to reduce same-room echo and feedback. It also improves WebRTC connection stability, mobile microphone handling, messaging reliability, video/media loading, post backgrounds, marketplace, payments, and Scrolitha production updates.
</en-US>
