# Scrolith Android 1.1.45 (55)

Stability and performance release for the latest Scrolith production experience.

## What's New

- Uses a new Play Store version code after version code 54 was already consumed.
- Improves production readiness for simultaneous video autoplay in posts, stories, and Scroll.
- Keeps hardened video streaming with byte-range playback, durable media cache headers, and safer metadata handling.
- Preserves mobile voice/video calling, call ringtone support, admin video controls, post backgrounds, messaging, marketplace, and Scrolitha updates.

## Quality

- Production web assets are rebuilt for the Android bundle.
- Capacitor Android sync is validated during release packaging.
- Release build uses minification and resource shrinking.
- Production endpoint validation rejects candidate/run.app API endpoints.
- Google Play upload is manual only.
