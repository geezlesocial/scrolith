# Scrolith Android 1.1.44 (54)

## Google Play Release Note

Scrolith now supports simultaneous autoplay for visible videos in posts, stories, and Scroll.

This release improves video streaming reliability, mobile playback smoothness, and media loading behavior across Android devices. It also includes the latest production updates for voice/video calling, call ringtone support, admin video controls, post backgrounds, messaging, marketplace, and Scrolitha.

Google Play upload was not performed by automation.
