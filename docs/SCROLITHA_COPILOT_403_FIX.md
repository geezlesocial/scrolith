# Scrolitha Copilot 403 Fix

The 403 was generated by the Copilot surface gate, not by Ollama. The old response collapsed feature flags, beta allowlisting, and consent into generic 403 behavior. The hotfix exposes stable codes: `COPILOT_FEATURE_DISABLED`, `USER_NOT_IN_BETA_ALLOWLIST`, and `AI_CONSENT_REQUIRED`.

The cohort gate remains active. No authentication or consent control was weakened. Production generation is now Ollama-only after the gate passes.
