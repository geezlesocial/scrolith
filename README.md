# Scrolith | Professional Platform for Work, Talent, Business & Community

Scrolith is an all-in-one professional platform connecting networking, freelancing, jobs, marketplace services, content creation, messaging, communities, payments, and Scrolitha AI in one connected experience.

Built for professionals, freelancers, jobseekers, employers, creators, businesses, and communities.

## 🚀 Quick Start

### Prerequisites

- Node.js 18+
- PostgreSQL
- Redis
- Git
- Docker (recommended for local development)
