For any later YAML, use role-specific placeholders only (never values): `G1_MEMBER_USERNAME/PASSWORD`, `G1_FREELANCER_USERNAME/PASSWORD`, `G1_EMPLOYER_USERNAME/PASSWORD`, `G1_MODERATOR_USERNAME/PASSWORD`, `G1_ANALYST_USERNAME/PASSWORD`, and `G1_PLATFORM_ADMIN_USERNAME/PASSWORD`.
